# molecular_qm_util
Utilities for molecular electronic structure calculations with Simstack

## Automatic semantic version tags

Pushes to `main` now run semantic release based on Conventional Commits:

- `fix:` increments patch (for example `v0.2.0` -> `v0.2.1`)
- `feat:` increments minor (for example `v0.2.0` -> `v0.3.0`)
- `BREAKING CHANGE:` or `feat!:` increments major

The workflow creates and pushes the new Git tag automatically.
